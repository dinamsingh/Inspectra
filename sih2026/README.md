# Inspectra — SIH 2026 submission materials

Problem statement **SIH26034** — Software System to check compliance of Packaged Commodities under the Legal Metrology (Packaged Commodities) Rules, 2011 by scanning products, images and labels.

This directory contains the editable deck source, visual QA previews, and the evidence/claims references used while preparing the submission.

## Contents

- `deck/` — editable PowerPoint generation and validation code
- `preview/` — six slide raster previews for visual inspection
- `CLAIMS_LEDGER.md` — claim-to-evidence record for the submission
- `SOURCES.md` — external references used in the deck
- `OUTLINE.md` — slide content and structure

The final evaluator-facing prototype is linked from the submitted presentation when deployed.

## Important evidence boundary

The repository's quantitative benchmark is **synthetic validation of the Phase-0 measurement engine**. Physical laboratory validation has not been completed, so the deck does not present synthetic results as physical-camera accuracy.

The Android client and broader field workflow are product implementation work beyond the current Phase-0 measurement core.
